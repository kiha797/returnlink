# 리턴링크 · 의약품 반품 관리

모바일·PC 의약품 반품 관리 웹 앱입니다.

## 실행 및 배포

정적 사이트이며 별도의 빌드 단계가 없습니다. 웹 서버의 공개 디렉터리를 `dist`로 지정하세요. 카메라를 사용하려면 HTTPS 또는 localhost가 필요합니다.

로컬 실행: `python -m http.server 8080 --directory dist`

Cloudflare Pages 설정: 빌드 명령은 비워두고 출력 디렉터리는 `dist`로 지정합니다.

## 기능

- 1차원·2차원 바코드 자동 판독 (EAN, Code 128, Data Matrix, QR 등)
- 카메라 초점 재요청, 후면 렌즈 변경, 지원 기기의 조명·확대
- 스캔 완료 알림음과 매입처 선택 오버레이
- 일련번호 → 제조번호 → 상품코드 순서의 매입 기록 조회
- 매입 CSV 가져오기, 반품 등록 및 CSV 내보내기

## 현재 연동 범위

KPIS·공동인증서·도매상 ERP API는 아직 연결되지 않았습니다. 가져온 CSV 및 반품 기록은 사용하는 브라우저의 localStorage에 저장됩니다. 시연 데이터가 포함되어 있습니다.

바코드 판독 엔진은 ZXing WASM이며 라이선스는 `dist/assets/zxing-LICENSE.txt`에 있습니다. 초점·조명 등의 지원 여부는 기기와 브라우저에 따라 다릅니다.
